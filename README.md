# أداة فلترة وطباعة تقارير الجرد (Excel to PDF Inventory Printer)

تطبيق ويب متكامل واحترافي يعمل بالكامل بدون إنترنت (Offline Ready) لمعالجة وفرز ملفات الجرد والإكسيل، وطباعتها أو تصديرها كملفات PDF عالية الدقة.

---

## 🌟 المميزات الرئيسية

1. **معالجة وفرز تلقائي لملفات الإكسيل (`.xlsx`, `.xls`, `.csv`)**:
   - استخراج وتنسيق كود الصنف تلقائياً من المسمى (مثال: `[0000094128] DOVE SHAMPOO` -> كود `[0000094128]` واسم `DOVE SHAMPOO`).
   - ترتيب تلقائي أبجدياً (A to Z) حسب اسم الصنف.
   - فلترة الأعمدة واختيار الأعمدة المطلوبة فقط وحذف الأعمدة غير الضرورية.

2. **ترويسة مخصصة ومطابقة للاستورات**:
   - إمكانية الاختيار السريع من بين 50 رقم لكل قسم (`COSMATICS 1-50`, `MEDICINE 1-50`, `MILK 1-50`, `DIAPER 1-50`).
   - إمكانية إدخال مسمى يدوي مخصص.
   - يظهر اسم الاستور بخط بارز في منتصف التقرير تماماً.

3. **تصدير وطباعة متعددة**:
   - **📥 حفظ كملف PDF**: تنزيل مباشر بنقرة واحدة باسم الاستور تلقائياً (مثال: `COSMATICS 1.pdf`) بدون أي صفحات بيضاء، وبنفس التنسيق المعتمد.
   - **🖨️ طباعة فورية**: طباعة نظيفة بتنسيق A4 أفقي (Landscape).
   - **تصدير إكسيل**: إمكانية تصدير البيانات المفلترة إلى ملف إكسيل جديد.

4. **دعم كامل للغات**:
   - إمكانية التبديل بين المسميات باللغة الإنجليزية (English) أو العربية (العربية).

---

## 🚀 طريقة التشغيل

### محلياً على جهاز الكمبيوتر:
1. قم بفتح الملف `index.html` مباشرة في أي متصفح (Chrome, Edge, Firefox).
2. أو اضغط مرتين على ملف `تشغيل_البرنامج.bat`.

### التشغيل عبر GitHub Pages (رابط مباشر أونلاين):
عند تفعيل **GitHub Pages** من إعدادات المستودع، يصبح التطبيق متاحاً عبر الرابط الدائم:
`https://<username>.github.io/<repository-name>/`
